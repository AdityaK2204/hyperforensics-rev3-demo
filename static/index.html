    Evidence on the file as received

    Eight hand-built cues from six physical origins, plus one learned erasure detector (C9). Each score is compared with a threshold that was fixed on undamaged files and never moved.

    Lifecycle: we damage the file ourselves

    The file is taken down the nine-rung ladder and through every ordering of four everyday events. All cues are read again at each step, which shows how long this file's evidence lasts and which cues move together.

    3

    Fusion: the two pipelines meet

    The lifecycle run says how damaged the file is and whether each cue's reading survives a re-save. That sets how far each cue is trusted and which cues are linked. The graph network then reads the evidence through those links.
